# ScholarFund – Decentralized Scholarship Funding System

ScholarFund allows communities, sponsors, or organizations to pool funds together and support students with transparent, traceable scholarship distributions.

## Core Capabilities
- Contributors deposit funds into a shared pool
- Scholarship applicants register for support
- DAO/community selects approved beneficiaries
- Distribution tracked on-chain for accountability

## Key Functions
contribute, apply-scholarship, approve-beneficiary, distribute, get-pool-info, get-beneficiary-info
